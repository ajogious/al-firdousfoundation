# 🌍 Al-Firdous Humanitarian Foundation Website

This is the official website of **Al-Firdous Humanitarian Foundation (AHF)**.  
Our goal is to create an accessible platform to share our mission, vision, and activities with the world.

## 💡 About Us

**Al-Firdous Humanitarian Foundation (AHF)** is an organisation that provides humanitarian services, advice, and support to the vulnerable.  
We are dedicated to uplifting communities through education, empowerment, and relief efforts.

## 🚀 Features

- Modern responsive design (HTML, CSS, JS, Bootstrap)
- Contact form using PHP
- Easy navigation and user-friendly layout
